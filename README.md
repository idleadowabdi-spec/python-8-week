## Project Description

My Personal Mini-Toolkit is a Python program that combines several useful tools into one menu-driven application.

The toolkit contains three tools:

1. Simple Calculator
2. To-Do List
3. Number Guessing Game

The program displays a menu and continues running until the user chooses the Quit option.

## Tools

### 1. Simple Calculator

The calculator allows the user to enter two numbers and choose addition, subtraction, multiplication, or division.

### 2. To-Do List

The To-Do List allows the user to add tasks, view tasks, and remove tasks. The list changes while the program is running.

### 3. Number Guessing Game

The Number Guessing Game asks the user to guess a secret number between 1 and 10. The program tells the user whether the guess is too high or too low.

## How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code.

Open the VS Code terminal and run:

```bash
python toolkit.py
```

The program will display the main menu.

Choose:

* `1` for Simple Calculator
* `2` for To-Do List
* `3` for Number Guessing Game
* `4` to Quit

## Reflection

The hardest part of this project was combining different Python concepts into one complete program. I had to make sure the main menu continued to appear after each tool finished. The bug that took the longest to fix was handling invalid user input without causing the program to crash. I learned that loops are useful for keeping a program running until the user decides to stop. I also learned how lists can change while a program is running by adding and removing tasks. With one more week, I would add a password generator and a countdown timer. I am proud that my program is organized into functions and is easy for another student to understand.
